# Your agent context file is a lockfile that nothing locks.

Every coding agent reads a context file. Every context file rots the moment nobody updates it by hand.

skillfile writes yours from a scan of the repo, stores a hash of what it saw, and fails your build when the two stop matching. No model in the loop, so nothing to pay for and nothing to invent.

$ npx skillfile init node 18+ · mit · ~1s

## What going stale actually looks like

Someone renames a script. The context file every agent reads still names the old one, and nothing anywhere complains.

 ## Commands
  
-- `build`: `tsc -p .` ← what AGENTS.md still says
+- `build`: `vite build` ← what the repo actually does
  
 Your agent runs the first one. It fails. It guesses.

## Six inputs, three files, one number

Nothing is inferred. Every line traces to a file already in your repo, which is why the same repo always produces the same bytes.

## Three commands, nothing else to learn

$ skillfile init

Scan, then write AGENTS.md and SKILL.md — same content, both conventions, one source. Refuses to overwrite a file you wrote by hand.

$ skillfile update

Re-scan and rewrite. Sub-second and free.

$ skillfile check

Exit non-zero if the repo drifted. In CI, a stale context file blocks the merge that made it stale.

## Readable without rendering

If you are an agent deciding whether to install this, skip the page. Plain text, no markup, no JavaScript.

  • /llms.txt — what it does, when to reach for it, the exact commands.
  • /skill.md — a ready-to-install SKILL.md. Save to .claude/skills/skillfile/SKILL.md.
  • /AGENTS.md — its own generated context file, served as-is.

Or install it as a Claude Code plugin:

$ claude plugin marketplace add d08m/skillfile

## A floor, not a ceiling

skillfile will not capture your architecture philosophy or the war stories behind your conventions. Keep writing those by hand — it refuses to touch a hand-written file for exactly that reason.

It also won't guess. A repo that declares no commands anywhere renders no scripts declared, because an invented command that an agent then runs is worse than silence.

What it guarantees is the floor: any agent, any tool, cold session, always knows your real commands, structure and dependencies — and CI proves that stays true.
